What makes it different

Six features, each doing one job well

NewsBot is built to run unattended for years. Every piece is designed to fail quietly, cost nothing, and stay configurable without touching a line of Python.

💸 Free forever

Zero paid subscriptions, zero paid APIs.

Every source is a free public feed. Delivery is Gmail SMTP. Scheduling is GitHub Actions. There is no load-bearing paid dependency anywhere in the stack — so it can't quietly start charging you.

  • Public RSS/Atom + GitHub releases + Google News
  • Gmail SMTP for delivery (free)
  • GitHub Actions cron (free tier)
  • Phase-1 pipeline needs no API keys at all

🛡️ Fail-soft by design

A dead feed logs and skips. It never crashes the run.

Every network call is wrapped. A rate-limited endpoint, a broken feed, a single malformed entry — each one degrades gracefully. And if the whole run somehow fails, it emails you the traceback so a broken pipeline is visible, never silent.

  • Per-feed and per-entry error isolation
  • Enforced timeouts + proper TLS on every request
  • Failure emails you the stack trace automatically
  • Missing LLM keys are skipped silently, not fatally

🔗 Smart de-duplication

Never see the same story twice.

URLs are canonicalized — tracking params stripped, hosts lowercased — so the same article with different UTM tags collapses into one. Then fuzzy title matching catches the same story surfacing from two different sources. A committed seen.json guarantees nothing re-sends across days.

  • UTM / gclid / fbclid tracking params stripped
  • Fuzzy title matching across sources (85% threshold)
  • Persistent seen.json prevents cross-day repeats

🎚️ Tiered sources & noise gate

High-signal feeds trusted. Noisy ones held to a higher bar.

Sources are tiered by reliability. Native blogs and GitHub releases clear on a single keyword hit. Noisier Google Alerts and Reddit must earn ≥2 hits before they qualify. Then per-topic and global caps keep the digest tight — precision over volume.

  • Weighted keyword scoring (title > summary) + recency bonus
  • Tier-aware noise gate filters low-signal chatter
  • Per-topic + global caps prevent digest bloat

🧭 Daily throughline

Insight, not just more headlines.

An optional free-LLM layer reads the day's items and writes a ≤3-sentence synthesis at the top of the digest — the what's actually shifting line that no single vendor blog can give you. With no key present it falls back to a deterministic heuristic, so the slot is always useful.

  • Free-LLM fallback chain: Gemini → Groq → OpenRouter → floor
  • Deterministic heuristic when no key is set
  • Optional per-item summaries, off by default

🔎 On-demand research

Search everything on a topic, right now — for free.

Beyond the daily digest, run an ad-hoc deep-dive on any topic. Backed by Google News RSS + Hacker News (no paid search API), it fetches the freshest relevant items, dedups them, and returns a synthesized briefing — or a clean ranked list when no LLM key is present.

  • One command: python -m src.research "topic"
  • Adjustable lookback window & item cap
  • Writes an HTML brief; --email sends it too
